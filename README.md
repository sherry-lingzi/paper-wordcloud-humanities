# 科学文献词云生成器

基于ar5iv HTML格式的科学文献词云生成工具，专门用于批量处理arXiv论文并生成高质量词云可视化。

## 功能特点

- 🚀 基于ar5iv的快速HTML文本提取
- 🧠 科学文献特化的NLP处理
- 🎨 多样化词云生成选项
- 📊 批量处理和分析功能

## 安装依赖

```bash
pip install -r requirements.txt
```

## 使用方法

```bash
python main.py
```

## 项目结构

```
├── src/           # 源代码
├── data/          # 原始数据
├── output/        # 生成的词云图片
├── tests/         # 测试文件
└── requirements.txt
```
